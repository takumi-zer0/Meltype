# Handyに組み込んだZeroVoice

個人用のHandy 0.9.8改変版。補正画面はHandyの中に表示される。標準の音声認識ショートカットを使い、話し終えた後に原文・文脈・候補を確認する。内容を確認したチェックを付けて、貼り付けまたはコピーする。

補正モデルはローカルのGemma 4 E2B。アプリ起動時にモデルを読み込む。補正速度は短文の合成例で中央値2.32秒だが、モデル初回準備は別に必要（測定環境で約8秒、別の推論アプリとの競合中は約28〜32秒）。他のGPU処理や文章の長さによって補正も遅くなる。[比較と既知の失敗](Handy-ZeroVoice-comparison-ja.md)を参照。

## Windows

ZER0-GALLERIA / frontにはモデルと個人版を配置済み。スタートメニューの **Handy ZeroVoice** から起動できる。アプリは `%LOCALAPPDATA%\Handy-ZeroVoice\app-9662b9f\handy.exe`。元のHandyは保持している。配布物のCLI・補正エンジン・合成2例の実行は確認済み。実際のマイクからの入力・貼り付けは未検証。

MeltVoiceの別モデルがGPUを使っていることを確認したため、個人版Handyへの再起動切り替えはまだ行っていない。MeltVoiceと元のHandyを終了してから、**Handy ZeroVoice** を起動する。

別のWindows環境で導入する場合:

1. 配布フォルダー内の `Setup-Model.ps1` を実行する。モデル約3.35 GBをダウンロードし、SHA-256を確認する。管理者権限は不要。保存先は `%LOCALAPPDATA%\Handy-ZeroVoice\models`。
2. 現在起動しているHandyをトレイから終了する。Handyは一つしか同時起動できない。
3. 配布フォルダー内の `handy.exe` を起動する。既存の音声認識モデルとショートカットを使用する。

既存のHandy設定でZeroVoiceを外部プログラムに指定していても、この改変版の通常録音ではHandy内のレビューが使われる。旧Handy本体・旧ZeroVoiceを削除する必要はない。元に戻すときは改変版をトレイから終了し、元のHandyを起動する。

## macOS

macOS 14以降。Apple SiliconとIntelで対応するアーカイブを使う。展開後、`Setup-Model.command` でモデルを取得する。保存先は `~/Library/Application Support/Handy-ZeroVoice/models/`。

M4のMacは `Handy-ZeroVoice-osx-arm64.tar.gz` を使う。Apple Silicon版はCIでビルド・補正56項目・連携2項目・同梱エンジン起動・アプリのCLI起動・署名整合性を確認済み。配布アーカイブはダウンロード後にもSHA-256と内部マニフェストを確認した。

既存Handyを終了してから `Handy.app` を起動する。文脈取得・貼り付けにはアクセシビリティ許可が必要で、許可できない場合はコピーを使う。マイク権限も通常のHandyと同様に必要。個人ビルドは開発者証明書で署名・公証されていないため、macOSの確認が必要になることがある。OSの保護機能を一括で無効化するスクリプトは含めていない。

Macでの実機マイク・入力先アプリとの操作試験は未実施。ビルド・補正ロジックのテスト結果と、実機の権限・入力互換性は別に扱う。

## 動作と制限

- 新規録音と認識結果をHandy履歴へ保存しない。既存の履歴は削除しない。
- 通常録音の結果をクラウドの後処理や外部プログラムへ転送しない。補正は専用子プロセスの標準入出力で行う。
- 原文・文脈・候補の編集で確認状態を解除する。元の入力欄・カーソル位置・周辺文を検査してから貼り付ける。
- Enterによる送信は行わない。コピーした文章はOSのクリップボードへ残る。
- 入力欄を確認できない場合はコピーのみ。すべてのアプリの特殊な入力欄に対応する保証はない。
- GPT-6 Luna APIは合成文で比較済みだが、このHandyの通常入力には未接続。Ollamaの共有サーバーは未導入。クラウドへ自動で切り替わる処理はない。
- 公式の自動更新ではこの改変版を置き換えない。更新時はソースの変更と再ビルドが必要。
