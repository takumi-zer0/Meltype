# ZeroVoice

## Handyへの組み込み版

`handy/Handy.patch` はHandy 0.9.8のコミット `48a3d8e9ee456c1c6a3b7223779271c457890b4d` に適用する変更です。音声認識後、Handy内に原文・文脈・補正候補を表示し、確認した候補を入力します。Windows x64・macOS 14以降のApple Silicon / Intel用のビルドを `handy/build.yml` で生成します。個人用ビルドには開発者証明書による署名・Appleの公証はありません。

補正は `src/ZeroVoice.Worker` の常駐モデルで実行します。Gemma 4 E2Bの公式QAT Q4_0 GGUF（約3.35 GB）と、固定したllama.cpp b11552を使います。Handy起動時に読み込み、専用の標準入出力で文章を渡します。公開HTTPサーバーは起動しません。モデル初回準備は別にかかります。利用者の文章と文脈を指示キャッシュへ保存しません。

文脈取得は録音開始時。入力欄の状態を再確認してから貼り付けます。補正された文を編集すると確認状態を解除します。新規の音声・文字起こしはHandyの履歴へ保存せず、既存の履歴は削除しません。Handyの自動送信・外部プログラム・クラウド後処理の設定は、この通常録音の出力経路では使いません。公式版の自動更新は無効にしています。

単語の補助辞書に加えて文全体を処理し、助詞、句読点、誤認識、話し言葉を補正します。意味を変えてしまう誤りが残るため、毎回候補を確認します。モデル・通信の方式だけで補正の正確さは保証できません。Mac実機のアクセシビリティ権限・全アプリへの貼り付けは未検証です。

Macはアーカイブ同梱の `Setup-Model.command` でモデルをダウンロードして検証します。モデルは `~/Library/Application Support/Handy-ZeroVoice/models/` に保存し、署名したアプリ本体の中身は変更しません。Windowsのモデル保存先は `%LOCALAPPDATA%/Handy-ZeroVoice/models/` です。クラウド送信と共有サーバーはまだ組み込んでいません。

以下は以前の**独立アプリ版**の説明です。組み込み版では `Connect-Handy` の操作は不要です。

## 独立アプリ版

Handyで認識した日本語を、ローカルモデルで校正し、確認してから入力する個人用アプリです。
WindowsとmacOSで同じ補正・確認画面を使います。Meltypeの「文脈と用語候補を使う」考え方を参考にした独立実装で、MeltypeのIME・変換エンジンのコードは含めていません。

「仕様／使用／私用」「校正／公正／構成／更生」「精算／生産／清算」「回答／解答」「保証／保障／補償」は、複数の文脈語が一致し、他候補より根拠が十分多い場合に辞書で候補を選んでからモデルへ渡します。複合語の途中は置換せず、根拠が弱い・競合する場合はそのまま残します。この判定にも誤りはあり得るため、補正案は確認してから使ってください。検証例と限界は `VALIDATION-ja.md` を参照してください。

個人用の初期版です。Windows x64、macOS 14以降（Apple Silicon / Intel）を対象とします。Mac実機の権限・入力操作は未検証です。OSの署名警告が出る場合に保護設定を一括無効化するスクリプトは含めていません。

Macでは対応するアーカイブを展開し、フォルダーを置きたい場所に移動してから `Setup-Model.command` を実行してください。固定した配布元から約2.5GBのモデルを取得し、SHA-256を照合します。続いて `ZeroVoice.app` を起動します。Handyと接続した後はフォルダーを動かさず、移動するときは先に連携解除してください。

## 使い方

1. `ZeroVoice.exe`（Macでは `ZeroVoice.app`）を起動します。単独でも日本語を入力して補正できます。
2. Handy連携は、Handyをトレイ／メニューバーから終了してから設定します。Windowsは同じフォルダーの `Connect-Handy.ps1`、Macは同梱の接続スクリプトを使います。
3. Handyを起動し、通常の音声認識ショートカットで話します。認識結果がZeroVoiceに渡ります。HandyのAI後処理用ショートカットは使いません。
4. Handyから受け取った文は自動でローカル補正します。原文・入力する文・文脈を確認します。文脈欄は編集・不使用にでき、変更後は「ローカルで補正」でやり直せます。
5. 内容を確認したらチェックを入れ、コピーまたは元の入力欄への貼り付けを選びます。文を編集するとチェックは解除されます。

接続スクリプトはHandyの貼り付け方法・外部プログラム・自動送信・AI後処理・クリップボード操作の5項目を変更し、変更前の5項目だけを復旧用に保存します。APIキー・ショートカット・音声認識モデルは変更しません。解除は `Disconnect-Handy.ps1` またはMacの解除スクリプトです。後から変更された設定があれば復旧は上書きせず停止します。

## 入力とプライバシー

- IME登録・管理者権限・自動起動・自動更新は使いません。
- 補正結果の自動入力・Enter送信はありません。意味の保存を完全に判定できないため、毎回確認します。
- 認識文は、Handyの外部プログラム機能から単一引数として渡されます。シェルを介しません。ただしOSのプロセス情報を閲覧できる同一ユーザー／管理者には引数が見える場合があります。Handy自身の履歴設定は別です。
- 推論はllama.cppのローカルプロセス。HTTPサーバーは起動せず、両OSとも起動した子プロセス専用の標準入力から文章を渡します。モデルへ渡す文をコマンド引数や一時ファイルに入れません。
- モデル・推論実行ファイル・依存DLLのSHA-256を検証します。同一ユーザーが既に侵害されている場合や、OS／モデル実行ライブラリにある未知の欠陥まで防ぐものではありません。
- 元の入力欄から最大1200文字の文脈を取得します。OSが秘密入力欄と判定した欄・既知のターミナルアプリは対象外です。アプリ内蔵のターミナルや独自の秘密入力欄をすべて識別できる保証はありません。取得できない場合は手動文脈・コピーを使えます。
- 貼り付け直前に入力先・カーソル位置・周辺文を検査します。OSのフォーカス変更とキー注入は完全に原子的ではないため、貼り付け中に別ウィンドウへ切り替えないでください。より確実に自分で入力先を選ぶ場合はコピーを使ってください。
- 確認した文をコピーするとOSのクリップボードへ残ります。通常のアプリ実行で文章の履歴・ログをファイル保存しません。
- Macの文脈取得・貼り付けにはアクセシビリティ許可が必要です。権限を自動で付与する処理はありません。
- Handyの自動送信はオフのまま使ってください。Handyの仕様上、オンに戻すとZeroVoiceを閉じた後にHandy側がEnter等を送る可能性があります。

## ローカルモデル

初期構成は [Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507) の [bartowskiによるQ4_K_M量子化版](https://huggingface.co/bartowski/Qwen_Qwen3-4B-Instruct-2507-GGUF) とllama.cpp b11552です。量子化ファイルはQwen自身の配布ではありません。モデルは約2.5GB。配布リビジョン `ae44f08e1392f39c0e474af10c3ff8355c8b6688`、SHA-256 `2fde00ce69dd4899c70d020845e2638353015bba0fdf161b3eb965f2bca4464e` に固定しています。

固定の校正指示をセットアップ時に事前計算して再利用します。認識文・周辺文はキャッシュへ保存しません。通常の補正ではキャッシュを読取専用で使い、SHA-256を毎回照合します。モデル・推論ファイル・設定・指示が変われば古いキャッシュは使いません。破損時は原文へ戻します。再生成は `ZeroVoice.exe --prepare-cache`（Macは `Setup-Model.command` の再実行）です。

実行ごとのモデル検証・ロードは維持しています。速度と精度は合成例の測定結果を参照してください。クラウド送信は実装していません。入力文の校正に使うJSON以外を実行する機能、外部ツール呼び出しはありません。

## 開発

.NET SDK 10でビルドします。共通処理は `src/ZeroVoice.Core`、Avalonia UIは `src/ZeroVoice.Desktop`、入力先連携は `src/ZeroVoice.Windows` と `src/ZeroVoice.Mac` です。

```
dotnet run --project tests/ZeroVoice.Tests -c Release
dotnet run --project tests/ZeroVoice.UiTests -c Release
dotnet build src/ZeroVoice.Desktop -c Release
```

ベンチマークは明示的に指定した合成例だけを保存します。

```
ZeroVoice.exe --benchmark cases.json results.json
```

手動試験: 意味の反転、質問への回答、数値の変化、長文、モデル故障、連打、補正後編集、入力先変更、カーソル移動、秘密入力、ターミナル、Handy接続と解除、Macの権限拒否と許可を確認してください。実機未検証の項目は検証レポートに明記します。

ソースと同じ `ci/zerovoice.yml` をforkの `.github/workflows/zerovoice.yml` に置くとWindows/Macのビルドと共通テストを実行できます。CIでもMac実機の権限を自動許可することはありません。
